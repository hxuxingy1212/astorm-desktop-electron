平台能力

Astorm 是一个本地优先的桌面智能体平台。它不只是聊天：能读写文件、运行命令、操作 Git、查资料、 做 Office 文档，并把每一步过程留在可审查的会话里。

概览

同一套 Rust 内核与 Vue 渲染层，可以在桌面客户端、本地 CLI、单用户云容器三种宿主中运行。 业务逻辑、工具协议、会话记录与数据格式不分叉；差别只在“入口”和“执行宿主”。

  • 过程透明：思考、工具调用、参数、结果、耗时与用量都进入对话过程收纳块，可展开查看。
  • 副作用可控：计划 / 执行 / 自动三种会话模式，配合手动授权 / 自动授权与审批卡。
  • 数据本地：会话、工作区、记忆与知识库默认落在本机；模型密钥经系统安全存储加密。
  • 模型可换：OpenAI、Anthropic、DeepSeek 或任意兼容端点，按供应商与模型配置。

三种运行形态

形态入口执行与数据适合
桌面客户端 Electron 原生窗口 本机文件、终端、浏览器与 Office；数据留在本机 日常主力、需要完整桌面能力
本地 CLI astorm 命令 同一内核，无窗口运行；审批与状态可脚本化 CI、定时任务、自动化脚本
云容器 浏览器 Web UI / HTTP API / CLI 单用户容器 + 数据卷；任务常驻，多设备接入 远程办公、跨设备、长时间任务

桌面端通过 napi 在进程内直连内核；Web 端通过同形的 window.api 契约走 REST + WebSocket。 渲染层与工具行为保持一致，桌面独有的系统能力在 Web 端按能力矩阵降级。

对话与任务

流式与过程

  • 流式正文、思考链、工具步骤；过程默认收起，一轮结束显示总耗时，点开可看完整轨迹。
  • 工具行展示类型、调用摘要、参数与结果；写文件显示增删行数与 diff，命令显示退出状态与输出。
  • 每轮结束展示交付物、变更文件、相关网页来源与相关记忆。

模式与审批

  • 计划只读分析与规划；执行按审批策略动手；自动在安全规则内自动放行。
  • 审批卡展示分类、来源、目标路径或命令；支持一次性授权与本会话授权。
  • 提问表单、邮件发送确认、工具失败与用户打断都有独立状态，不靠正文猜测。

会话操作

  • 消息队列、立即发送、停止生成；撤回、派生新会话、摘要压缩、加载更早。
  • /plan 计划模式、/goal 目标循环；目标可修改、暂停或结束。
  • 子会话与多智能体并行：一次委派可并发多个子任务，入口收在会话右上角。

引用与附件

  • 正文文件引用（auth.rs:47）可点击打开文件页签并定位到行；网页引用以编号角标打开内置浏览器。
  • 支持图片、任意文件、网页元素、Office 元素与对话引用；发送时随消息作为结构化元数据下发。

工具与执行

  • 文件：读取、写入、编辑、追加、列目录、glob、grep；返回行数、字符数与 diff。
  • 命令：bash / PTY；支持超时、输出截断、沙箱事实标注（无防护、被驱逐、被截断）。
  • Git：状态、差异、分支、提交历史与图谱；工作区分支在顶栏实时展示。
  • 检索：网页搜索、网页抓取、GitHub、arXiv、会话历史。
  • 浏览器：打开页签、导航、点击、输入、读取页面；与用户共享同一个页面。
  • Office：Word / Excel / PPT / PDF 的生成、读取、编辑、渲染与格式转换。
  • 邮件：多账号 IMAP/SMTP，列表、正文、附件、标记与发送；发送前必须确认。
  • 记忆：概念检索与每轮注入；技能 / 智能体：按会话挂载与委派；MCP：远程工具接入。

工具按会话与智能体授权，部分工具按需加载。所有写操作、网络访问与危险命令都先经过静态预检与审批策略， 再进入系统级沙箱执行。

工作区与预览

  • 文件树：按会话工作区浏览、搜索、展开；文件预览支持语法高亮、行号与 markdown 渲染。
  • 代码审查：按 git 变更列出文件与 diff，支持逐行查看和跳转。
  • 终端：交互式 PTY；切换页签不断连，关闭页签才断开。
  • 浏览器页签：桌面用 iframe + CDP，Web 用服务端 Chromium 画面流；支持元素拾取、截图与录像（桌面）。
  • Office 预览：docx / xlsx / pptx / pdf 高保真渲染；可悬浮元素路径回填输入框。
  • 多页签与分栏：文件、终端、浏览器、Office、审查、会话轨迹并列；宽度两档、可拖拽、可最大化。

知识与交付

  • 交付物：跨会话汇总生成的产物，按今天 / 昨天 / 近一周 / 近一月筛选，按会话与轮次两级折叠；支持打开与审查。
  • 资料库：文件树、文件夹、颜色、标签、导入、搜索、预览、重命名与删除。
  • 长期记忆：原始资料 → OKF 概念编译 → 概念卡片与检索；每轮按相关度注入，不等同于普通文件库。

交付物是“这轮工作产出了什么”，资料库是“你交给它的资料”，记忆是“它沉淀下来的概念”。三者分开管理。

自动化与协作

  • 定时任务：每天 / 每周 / 工作日 / 自定义 cron；每次新建会话或持续复用同一会话；可启停、立即运行、查看执行记录。
  • 任务看板：待办 / 进行中 / 待处理 / 已完成；新建待办、启动、修改状态。
  • 邮件代理：多账号收件箱、文件夹计数、未读与标记；写邮件、附件、发送确认卡。
  • 目标与计划：目标循环自动推进；任务规划支持步骤状态与详细说明。

模型与扩展

  • 供应商：支持 Chat Completions、Responses、Anthropic Messages 三种协议；自定义 Base URL 与 API Key。
  • 模型：同一供应商下可配置多个模型；可检测文本与图片识别能力；列表第一项为默认。
  • 会话级设置：模式、权限、思考强度、供应商与模型按会话保存，改动即时生效。
  • 技能：内置 office 技能，用户技能可导入 / 启用；对话中可用 $ 引用。
  • 智能体：内置主智能体、General、Explore，以及自定义智能体；可配置工具集、技能集、模式与权限。
  • MCP：stdio 与 HTTP 连接器，工具并入当前会话；远程 401 支持 OAuth 或手动 Token。
  • 插件：桌面端可安装、配置与打开插件页；Web 端不提供安装入口。

安全与审计

  • 两套正交维度：会话模式（计划 / 执行 / 自动）× 权限模式（手动 / 自动）；硬规则始终优先于自动放行。
  • 审批信息：分类、来源、目标路径、命令与原因；支持一次性或本会话授权。
  • 沙箱：系统级隔离（macOS Seatbelt、Windows AppContainer 等）；运行结果标注无防护、被驱逐、超时或输出截断。
  • 凭据：模型密钥经 Electron safeStorage 加密；云容器依赖数据卷权限边界；远程 MCP 使用连接器凭据。
  • 审计与用量：工具调用、审批与拒绝进入审计日志；按会话与时间统计 token 用量。

数据与部署

  • 系统目录：config/、data/、log/、plugins/、skills/、electron/。
  • 用户目录：workspace/ 任务工作区、knowledge/ 资料库、memory/ 长期记忆。
  • 存储：SQLite 元数据 + 每会话 message.jsonl；交付物、定时任务、用量与审计各有表。
  • 云容器：单用户实例 + 持久化数据卷；Web UI、HTTP API 与 CLI 同源；模型供应商在 Web 设置中配置。
  • CLI：astorm newtask / tasks / show / stop / pending / approve / status，适合脚本与 CI。

平台支持

  • 桌面：macOS、Windows、Linux；原生窗口、系统对话框、本机文件管理器、Chrome Cookie 导入。
  • Web：浏览器访问云容器；服务端浏览器画面流、文件上传 staging、服务端目录选择器。
  • 桌面独有：元素拾取、截图 / 录像、插件安装与插件站点、部分系统级集成。
  • Web 降级：无本机文件管理器、无 Chrome Cookie 导入、远程 MCP 的 OAuth 回环受限（可用手动 Token）。
  • Office：预览依赖随包分发的 office 套件；缺失时回退旧渲染器或外部打开。
